# CDC WONDER query guide

Multiple Cause of Death public aggregate data were taken from the Bridged Race 1999–2020 and Single Race 2018–2024 releases. Lung-cancer deaths use ICD-10 C34 as underlying cause; CKD co-recording uses N18 among multiple causes within C34-underlying deaths. The national grouped model uses years 2013–2024 and five known-age strata (<55, 55–64, 65–74, 75–84, ≥85). Cross-release overlap checks use 2018–2020; the analysis uses Bridged Race through 2020 and Single Race from 2021. Historical urbanicity rates use the 2013 scheme through 2020; contemporary count-based analyses use the 2023 scheme, 2018–2024, ages ≥55.

The `*_request.xml` files in `analysis/source/new_cdc_queries` specify the exact database release (D77 or D157), filters, grouping and requested fields for the saved revision queries. Companion `*_response.xml` files preserve returned results where available. Requests without responses are retained only as attempted specifications. The archived original exports retain the available footer metadata for the original rate and population queries. Use the programmatic raw request for exact selections where it is available, rather than inferring suppressed values from this summary.
